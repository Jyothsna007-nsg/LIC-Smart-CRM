# LIC Smart CRM

A professional **LIC Agent Assistant Platform** built using **React, Node.js, Express, and MySQL**.

## Features

- Customer Registration
- Customer Management
- Policy Recommendation System
- Premium Calculator
- Follow-up & Renewal Tracking
- Analytics Dashboard (coming soon)

## Tech Stack

- **Frontend:** React + Vite
- **Backend:** Node.js + Express
- **Database:** MySQL
- **API Communication:** Axios

## Project Structure

```
LIC-Smart-CRM/
├── frontend/
├── backend/
├── database/
├── docs/
└── README.md
```

## Run Frontend

```bash
cd frontend
npm install
npm run dev
```

## Run Backend

```bash
cd backend
npm install
npm run dev
```
